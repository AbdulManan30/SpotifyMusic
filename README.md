# 🎵 Spotify Clone

A custom-built **Spotify Clone** using **HTML, CSS, and JavaScript**. This app mimics Spotify’s UI and core music functionality by playing local songs and organizing them artist-wise.

## 🚀 Features
- Play/pause, next & previous song controls
- Fetch songs from local folders
- Artist folders displayed as interactive cards
- Add new folders dynamically

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

---

> 🎧 A hands-on project for practicing DOM manipulation, event handling, and file-system interaction simulation.
